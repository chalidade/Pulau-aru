Kebijakan Privasi

Berlaku sejak 2 November 2026.

Halaman ini menjelaskan data apa yang dipakai Pulau Aru dan bagaimana data itu disimpan.

Pengunjung

Pulau Aru tidak memakai akun atau cookie pelacak. Untuk mengetahui jumlah pengunjung, setiap kunjungan menambah beberapa angka hitungan anonim (jumlah kunjungan, pengunjung per hari, sumber kunjungan seperti TikTok atau langsung) di layanan penghitung Abacus (abacus.jasoncameron.dev). Tidak ada nama, akun, atau data pribadi yang dikirim; yang tersimpan hanya angka total. Penanda "sudah dihitung hari ini" dan pengaturan game disimpan di penyimpanan lokal peramban kamu. Situs dihosting di GitHub Pages, yang dapat mencatat log teknis seperti alamat IP sesuai kebijakan GitHub.

Kreator yang menghubungkan TikTok

  • Data yang diambil: lewat Login Kit dengan scope user.info.basic dan user.info.stats, Pulau Aru membaca profil dasar dan jumlah follower akun kreator.
  • Data yang dipublikasikan: hanya jumlah follower, ditulis ke data/island.json dan ditampilkan sebagai jumlah penduduk pulau.
  • Token: token akses TikTok disimpan sebagai secret terenkripsi di GitHub Actions. Token tidak pernah ditulis ke repositori atau log publik.
  • Pencabutan: akses dapat dicabut kapan saja dari pengaturan TikTok (Keamanan → Kelola izin aplikasi). Setelah dicabut, sinkron berhenti.

Pulau Aru tidak menjual atau membagikan data kepada pihak lain, dan tidak membaca daftar follower.

Kontak

Pertanyaan atau permintaan penghapusan data dapat diajukan lewat GitHub Issues.
